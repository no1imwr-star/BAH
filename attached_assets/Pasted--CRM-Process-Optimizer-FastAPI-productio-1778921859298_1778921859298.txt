Полностью обнови и стабилизируй проект "CRM Process Optimizer" на FastAPI. Код должен быть production-ready, написан без синтаксических ошибок и полностью готов к деплою на Render.com.

Реализуй архитектуру проекта строго по следующим техническим требованиям:

1. Файловая структура и зависимости:
- Основной файл приложения: `main.py`.
- Файл `requirements.txt` должен содержать: fastapi, uvicorn, pandas, openpyxl, openai, python-multipart, jinja2.

2. Интерфейс (HTML-шаблоны внутри Python или в папке templates):
- Главная страница (`/`): Чистый современный интерфейс (используй cdn water.css для стилизации). Форма для загрузки файлов (.csv, .xlsx, .xls) и TextArea для ввода проблемы бизнес-процесса.
- Страница результатов (`/analyze`): Должна содержать блок со статистикой файла (кол-во строк, список колонок), интерактивное поле для рендеринга BPMN схемы и блок с ТЗ/Use Case в красивой темной плашке (white-space: pre-wrap).
- Подключи на фронтенд официальный BPMN-вьюер через CDN:
  <script src="https://unpkg.com"></script>

3. Бэкенд-логика и обработка файлов (FastAPI):
- В функции `/analyze` реализуй отказоустойчивое чтение файлов с помощью pandas. Перед вызовом pd.read_* ОБЯЗАТЕЛЬНО делай сброс указателя файла: `file.file.seek(0)`.
- Валидацию делай строго по расширению файла (`file.filename.lower().endswith`), полностью проигнорируй content_type (чтобы избежать багов с zip/xlsx). Для Excel принудительно укажи `engine='openpyxl'`.

4. Интеграция с Groq API и обход лимитов (Самое важное):
- Инициализируй клиент OpenAI с параметрами: base_url="https://groq.com", api_key=os.environ.get("GROQ_API_KEY").
- Для обхода лимита в 6000 токенов (Free Tier) НЕ отправляй в ИИ всю таблицу. Передавай в промпт только: строку проблемы, список названий колонок и общее количество строк.
- Используй модель "llama-3.1-8b-instant". Заставь её вернуть ответ в строгом формате, где элементы разделены вертикальной чертой '|':
  "Название Шага 1 (до 3 слов) | Название Шага 2 (до 3 слов) | Подробный текстовый Use Case по Коберну на русском языке"
- Оберни запрос к ИИ в try-except. Если ключа нет или запрос упал, код не должен выдавать ошибку 500, он должен переключиться в Демо-режим и подставить заготовленный шаблон.

5. Стабильная генерация BPMN:
- Напиши в Python базовую строку-шаблон валидного BPMN 2.0 XML кода, содержащую стандартные графические координаты (теги bpmndi:BPMNDiagram, BPMNPlane, BPMNShape), чтобы схема 100% отрисовывалась в браузере.
- Подставляй названия Шага 1 и Шага 2, полученные от Groq, внутрь этого XML-шаблона через f-строки. Передавай готовый XML на фронтенд для безопасного рендеринга через bpmn-js.

Убедись, что после написания кода ты автоматически проверишь его работоспособность, сделаешь коммит и отправишь изменения в GitHub репозиторий.
