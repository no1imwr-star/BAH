Добавь в проект функционал скачивания сгенерированной спецификации требований в форматах .docx (Word) и .pdf на выбор пользователя. 

Выполни следующие шаги:

1. ОБНОВЛЕНИЕ ЗАВИСИМОСТЕЙ
- Добавь в файл `requirements.txt` две библиотеки:
  python-docx
  xhtml2pdf

2. СОЗДАНИЕ ЭНДПОИНТОВ ДЛЯ СКАЧИВАНИЯ В main.py
Добавь в FastAPI два новых роута, которые будут принимать текст сгенерированной спецификации (или забирать его из сессии/кэша) и отдавать файл пользователю:

- Для Word (.docx):
  Используй `docx.Document()`. Напиши функцию, которая построчно читает Markdown-текст спецификации. Строки с `#` превращай в заголовки (`doc.add_heading(text, level)`), обычный текст — в параграфы, а таблицы — в таблицы Word. Отдавай файл как `StreamingResponse` с медиатипом `application/vnd.openxmlformats-officedocument.wordprocessingml.document`.

- Для PDF (.pdf):
  Используй библиотеку `xhtml2pdf.pisa`. Переведи Markdown-текст спецификации в простой HTML-вид (можно использовать библиотеку `markdown` или базовые автозамены тегов) и сконвертируй этот HTML в PDF через `pisa.CreatePDF()`. Чтобы русский язык не превратился в "кракозябры", обязательно укажи в стилях HTML-шаблона PDF системный шрифт, поддерживающий кириллицу (например, `font-family: Helvetica, Arial, sans-serif;`). Отдавай как `StreamingResponse` с медиатипом `application/pdf`.

3. ОБНОВЛЕНИЕ ИНТЕРФЕЙСА (Airbnb Style)
- На странице результатов (`/analyze`) рядом с кнопкой скачивания Markdown добавь блок "📥 Экспорт документации:".
- Размести две стильные аккуратные кнопки-ссылки:
  * Кнопка 1: "Скачать в Word (.docx)" — ведет на эндпоинт `/download/docx`
  * Кнопка 2: "Скачать в PDF (.pdf)" — ведет на эндпоинт `/download/pdf`
- Стилизуй их в общей кораллово-розовой или нейтральной серой гамме Airbnb ( border-radius: 8px, мягкий эффект hover).

4. ПРОВЕРКА ОШИБОК
- Оберни генерацию файлов в try-except. Если при создании PDF или DOCX происходит сбой, система должна выдать пользователю понятное текстовое предупреждение, не ломая основную страницу.

После написания кода сделай коммит и отправь (push) изменения в GitHub репозиторий.
