Создай веб-приложение на Python с использованием библиотеки Streamlit под названием "CRM Process Optimizer". Приложение должно быть полностью готово для деплоя на Render.com (создай файлы requirements.txt и runtime.txt с версией Python 3.10+).

Архитектура и стек:
- Фронтенд и бэкенд: Streamlit (для быстрого и чистого интерфейса) + pandas/openpyxl для работы с файлами.
- Визуализация BPMN: Используй библиотеку bpmn-js через компонент streamlit.components.v1.html. Схема должна рендериться интерактивно прямо на странице.
- Логика генерации: Интеграция с OpenAI API (используй актуальную библиотеку openai>=1.0.0). Ключ API должен считываться из st.secrets["OPENAI_API_KEY"] или переменных окружения. Предусмотри "демо-режим" (Mock data), если ключ не введен.

Функциональные требования:

1. Загрузка данных (Сайдбар или Главный экран):
- Поддержка загрузки файлов формата .csv и .xlsx/.xls (Excel).
- Поле TextArea для ввода текстового описания проблемы (например: "Сделки зависают на этапе ТЗ, менеджеры долго отвечают").

2. Под капотом (Промптинг для LLM):
- Напиши системный промпт для OpenAI, который заставляет модель проанализировать структуру загруженной таблицы (названия колонок, этапы воронки) и текст проблемы.
- Модель должна строго в одном запросе (или в два параллельных) выдать два результата:
  А) Валидный, синтаксически корректный BPMN 2.0 XML-код процесса "To-Be" (с пулами, дорожками менеджера и CRM-системы, задачами и шлюзами). Важно: XML должен открываться библиотекой bpmn-js без ошибок рендеринга.
  Б) Текстовый Use Case для разработчика по стандарту Коберна (Название, Акторы, Предусловия, Основной сценарий по шагам, Альтернативные сценарии, Постусловия).

3. Главный экран (Результаты):
После обработки данных покажи две вкладки (st.tabs):
- Вкладка 1: "Интерактивная BPMN схема". Здесь рендерится HTML-контейнер с bpmn-js, в который передается сгенерированный XML. Пользователь должен иметь возможность двигать и масштабировать схему. Добавь кнопку "Скачать BPMN (.bpmn)".
- Вкладка 2: "Use Cases / ТЗ". Красиво отформатированный текст в Markdown. Добавь кнопку "Скачать ТЗ (.md)".

Убедись, что код не содержит синтаксических ошибок, обработка ошибок загрузки файлов (try-except) реализована корректно, а интерфейс выглядит профессионально и лаконично для продуктового аналитика.
